Outcome and constraints

Rename the public product from Thread to One Blue Thread and make Scripture—not product prose—the primary voice. The app creates conditions to arrive, read, remember, and return, then becomes quiet. It never generates devotionals, summaries, prayers, interpretations, “takeaways,” or simulated spiritual authority.

Full-passage rule: any surface that cites Numbers 15 or explains the blue-thread origin contains Numbers 15:37–41 in full on that same surface, with translation and required notice. There is no excerpt-only or link-only exception. A constrained surface omits the citation and origin explanation entirely.

Preservation boundary

Keep the Loom visual identity and current woven icon. Preserve com.sngugi.thread, Expo slug thread, thread.db, SecureStore key names, backup format, event types, deterministic seed strings, build history, reading history, cloth, remembered passages, onboarding state, and experiments. Android must see the release as an update to the same app.

Scope and non-goals

In scope: installed name, passage/origin surfaces, voice policy and audit, notifications including already-pending requests, new backup names plus legacy compatibility, website/metadata, README/current docs, APK artifact label, release verification. Out: repo rename, package ID or database rename, schema/event migration, visual redesign, AI service, random decorative verses, app-store pipeline, and rewriting historical plans/journal entries.

Dependencies and gates

  • Search/ownership: exact-name search, relevant trademark-register search (not legal clearance), domain and key handle secured, canonical URL and renewal owner recorded. Blocks public launch.
  • NIV: permission must cover NIV 2011 on the bundled offline app, public source, APK/GitHub Release, GitHub Pages, OG/screenshots, and future marketing. If incomplete, ship the exact bundled WEB passage instead.
  • Content review: final factual context line reviewed by someone competent in Jewish biblical practice.

  • Pending/new notification titles change while identifiers, triggers, bodies, data, decisions, 4 AM logic, silence arms, and post-day-366 buckets remain identical.
  • New backup naming plus old import/cleanup, strict matcher near-misses, unrelated-file preservation.
  • git diff -- app.json proves slug/package unchanged; whole diff proves no schema/event/PRNG/time-boundary change.
  • Scoped rg search with every residual Thread/thread hit classified.
