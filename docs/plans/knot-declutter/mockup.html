The information architecture is already settled by the grill session and is identical in all three: an everyday tier (compact weave · the cue · reading history) over a rare tier grouped as Your data (Safekeeping, Starting over) · Practice (Partner, Adaptive policy) · About (Origin story, Support). What differs is how the second tier is reached — and that changes the build, so it needs deciding before the recipe. Every direction is achievable in React Native StyleSheet + Reanimated with no new dependency. Option A shows the resting state; B and C show the Safekeeping-needs-attention state, which promotes that section into the everyday tier already open.

Option A · Quiet list

One scroll, one level. "More" is a final row that expands in place into three labelled groups. Closest to today's code — the DisclosureSection primitive is reused unchanged, nested one deep.
